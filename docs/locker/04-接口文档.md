# 接口文档（22 个）

网关基址：`http://127.0.0.1:8080`，命名空间 `/api/v1/locker`。
用户标识统一走请求头 `X-User-Id`（缺省 `u_1001`）。资金与状态字段全部由服务端计算，不接受客户端指定。

## 0. 统一响应外壳

成功：

```json
{"request_id":"b1c2...","data":{...}}
```

失败：

```json
{"request_id":"b1c2...","error":{"code":"order_not_found","message":"order not found"}}
```

状态码映射：`INVALID_ARGUMENT→400`，`UNAUTHORIZED→401`，`NOT_FOUND→404`，`CONFLICT→409`，`INTERNAL→500`。

## 1. 首页与网点发现（工单 03）

### 1.1 GET /cities
查询参数：`keyword`（可选，匹配中文名或拼音首字母）。响应 `data`：

```json
{"items":[{"id":"city_512","name":"宿迁","province":"江苏","pinyin":"sq"}],"total":1}
```

查询：`city_id`、`keyword`、`lat`、`lng`、`page`、`page_size`。按距离升序（提供经纬度时）。

```json
{"items":[{"id":"st_001","name":"宿迁学院寄存点","city_id":"city_512","city_name":"宿迁",
"address":"宿迁职业技术学院北门","lat":33.96,"lng":118.28,"distance_m":860,
"free_count":7,"cabinet_count":10}],"total":1,"page":1,"page_size":20}
```

### 1.3 GET /stations/:id/cabinets

```json
{"station_id":"st_001","station_name":"宿迁学院寄存点","free_count":7,
"items":[{"id":"cab_001_01","code":"A-01","size":"M","status":"free"}]}
```

## 2. 物品寄存与计费（工单 04）

### 2.1 POST /quote 费用试算

```json
{"size":"M","hours":4,"coupon_id":"cp_001"}
```

响应：

```json
{"size":"M","hours":4,"unit_price_fen":450,"rent_fen":1800,"deposit_fen":1500,
"coupon_fen":500,"coupon_title":"新人立减5元","total_fen":2800}
```

计费规则：`租金 = 单价(尺寸) × 小时数`；`S=300 / M=450 / L=600 分每小时`；押金 `S=1000 / M=1500 / L=2000`；券额不超过租金，且需满足门槛；`total = 租金 + 押金 − 抵扣`。

### 2.2 POST /orders 下单并锁柜

```json
{"station_id":"st_001","cabinet_id":"cab_001_01","hours":4,"coupon_id":"cp_001"}
```

响应：

```json
{"order_no":"LK202611210001","station_name":"宿迁学院寄存点","cabinet_code":"A-01","size":"M",
"hours":4,"rent_fen":1800,"deposit_fen":1500,"coupon_fen":500,"total_fen":2800,
"status":"pending_pay","start_at":"2026-11-21T19:04:05+08:00","end_at":"2026-11-21T23:04:05+08:00",
"pay":{"pay_no":"PAY202611210001","amount_fen":2800,"channel":"alipay","idempotency_key":"PAY202611210001"}}
```

异常：柜门被占用返回 409 `cabinet_unavailable`；尺寸与柜门不符返回 400 `size_mismatch`。

### 2.3 POST /payments/notify 支付回调

```json
{"pay_no":"PAY202611210001","order_no":"LK202611210001","amount_fen":2800,
"idempotency_key":"PAY202611210001","success":true}
```

响应：

```json
{"order_no":"LK202611210001","status":"active","paid_at":"2026-11-21T19:05:10+08:00","duplicated":false}
```

金额不符返回 409 `amount_mismatch`；重复回调返回 `duplicated=true` 且不重复落单。

## 3. 订单查看与取出（工单 05）

### 3.1 GET /orders 当前与历史列表

查询：`status`（`all` 默认 / `active` / `overdue` / `completed` / `pending_pay`）、`page`、`page_size`。读取时将"已过 `end_at` 的 active 订单"惰性修正为 `overdue`。

```json
{"items":[{"order_no":"LK202611210001","station_name":"宿迁学院寄存点","cabinet_code":"A-01",
"status":"active","total_fen":2800,"end_at":"2026-11-21T23:04:05+08:00","hours_left":3}],
"total":1,"stats":{"active":1,"overdue":0,"pending_pay":0,"completed":0}}
```

### 3.2 GET /orders/:order_no 详情

```json
{"order_no":"LK202611210001","station_name":"宿迁学院寄存点","station_address":"宿迁职业技术学院北门",
"cabinet_code":"A-01","cabinet_size":"M","hours":4,"rent_fen":1800,"deposit_fen":1500,
"coupon_fen":500,"total_fen":2800,"overdue_fen":0,"status":"active",
"start_at":"...","end_at":"...","actions":["pickup","grant"],
"events":[{"node":"created","note":"下单锁柜","at":"..."},{"node":"paid","note":"支付成功 2800 分","at":"..."}]}
```

### 3.3 POST /orders/:order_no/pickup 取出

无请求体。`active` 可直接取；`overdue` 返回 409 `order_overdue`，需先补缴。成功后柜门释放为 `free`，订单转 `completed`，写入 `order_completed` 站内信。

```json
{"order_no":"LK202611210001","status":"completed","pickup_at":"...","cabinet_code":"A-01","cabinet_status":"free"}
```

### 3.4 POST /orders/:order_no/overdue-pay 超时补缴

无请求体。按 `end_at` 到当前时间向上取整小时，按 `单价 × 1.5` 计费。补缴成功解锁取件（订单转 `completed`）。

```json
{"order_no":"LK202611210001","status":"completed","overdue_hours":2,"overdue_fen":1350,"end_at":"..."}
```

### 3.5 POST /orders/:order_no/grants 临时开柜授权

无请求体。生成限时 15 分钟、限次 2 次的授权，与订单强绑定。

```json
{"grant_no":"GR202611210001","order_no":"LK202611210001","expire_at":"...","remain":2,"status":"active"}
```

### 3.6 POST /grants/:grant_no/use 授权核销

```json
{"grant_no":"GR202611210001","order_no":"LK...","remain":1,"status":"active","cabinet_status":"opening"}
```

过期或超出次数返回 409 `grant_expired` / `grant_exhausted`。

```json
{"items":[{"flow_no":"FL202611210001","biz_type":"recharge","amount_fen":10000,
```

```json
{"amount_fen":10000,"channel":"alipay"}
```

响应：`{"recharge_no":"RC202611210001","amount_fen":10000,"status":"processing","idempotency_key":"RC202611210001"}`

### 4.4 POST /recharges/notify 充值回调入账

```json
{"recharge_no":"RC202611210001","amount_fen":10000,"success":true}
```

响应：`{"recharge_no":"RC...","status":"success","balance_fen":12800,"flow_no":"FL...","duplicated":false}`

入账与余额明细在同一事务内写入；`amount_fen` 与充值单不符返回 409 `amount_mismatch`。

### 4.5 GET /recharges

```json
{"items":[{"recharge_no":"RC...","amount_fen":10000,"channel":"alipay","status":"success","created_at":"..."}],"total":1}
```

## 7. 场景编码（对齐工单 1）

| 编码 | 场景 | 触发点 |
| --- | --- | --- |
| `order_paid` | 支付成功 | 支付回调 |
| `pickup_reminder` | 取件提醒 | 下单成功后即发（对应到件提醒） |
| `order_completed` | 订单完成 | 取出/补缴完成 |
| `order_overdue` | 订单超时欠费 | 惰性判定转 overdue 时 |
| `grant_used` | 临时开柜授权已使用 | 授权核销 |
