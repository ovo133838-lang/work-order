## 4. 数据落库核对

接口返回之外，直接查询 MySQL 与 Redis 交叉核对（见 `docs/locker/test-evidence/db-check.txt`）：
- `lk_orders` / `lk_payments` / `lk_notices` / `lk_balance_flows` 行数与调用次数一致；
