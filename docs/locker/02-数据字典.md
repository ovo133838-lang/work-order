# 数据字典

库名 `bw_locker`，字符集 `utf8mb4`，引擎 InnoDB。表名统一 `lk_` 前缀，模型定义见 `internal/locker/model/models.go`，启动时由 Gorm `AutoMigrate` 建表。

金额字段一律 `bigint`，单位**分**；时间字段 `datetime`，接口输出 RFC3339。

## 1. lk_cities 城市

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | varchar(32) PK | 城市编码，如 `city_512` |
| name | varchar(64) | 城市名，索引 |
| province | varchar(64) | 所属省份 |
| pinyin | varchar(32) | 拼音首字母，索引，用于快速检索 |

## 2. lk_stations 网点（工单 3 称"寄存点"，同义）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | varchar(32) PK | 网点编码 |
| name | varchar(128) | 网点名称 |
| city_id | varchar(32) | 所属城市，索引 |
| city_name | varchar(64) | 冗余城市名，用于列表直接展示 |
| address | varchar(255) | 详细地址 |
| lat / lng | double | 经纬度，用于距离计算与排序 |
| open_at / close_at | varchar(8) | 营业时间 `08:00` / `22:00`，工单 1"营业前 30 分钟"场景的判定依据 |
| status | varchar(16) | `open` 营业中 / `closed` 停用，索引 |

## 3. lk_cabinets 柜门（工单中的"柜子/格口"）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | varchar(40) PK | 柜门编码，如 `cab_A_01` |
| station_id | varchar(32) | 所属网点，索引 |
| code | varchar(32) | 展示编号 `A-01` |
| size | varchar(8) | `S` / `M` / `L`，决定单价与押金 |

| current_order_no | varchar(40) | 当前占用订单号，索引 |
| version | int | 乐观锁版本号，每次状态变更 +1 |
| updated_at | datetime | 最后变更时间 |

## 4. lk_orders 寄存订单

| 字段 | 类型 | 说明 |

## 14. 索引说明

- 高频查询字段（`user_id`、`status`、`order_no`、`create_at`）均建普通索引，满足工单 5"对高频字段建立索引"的要求。
- `lk_payments.idempotency_key`、`lk_recharges.idempotency_key` 建**唯一索引**，是回调幂等的最后一道防线（Redis 幂等键失效时的兜底）。
- `lk_cabinets.status + station_id` 组合查询用于柜门列表，规模在千级以内，暂不建联合索引。
